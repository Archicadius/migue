# Migue 🔬

Квиз: смотрим фотографию с микроскопа и угадываем, что это за предмет.

Игру придумали и собрали Фёдор и папа. Фотографии — Фёдор.

## Как посмотреть у себя на компьютере

В папке проекта, в терминале:

```bash
python3 -m http.server 8000
```

Открыть в браузере: <http://localhost:8000>

(Просто открыть `index.html` двойным щелчком нельзя — не заработает
загрузка картинок и офлайн-режим. Нужен маленький локальный сервер.)

## Как добавить новые предметы

1. Сфотографировать предмет **обычной камерой** и **через микроскоп**.
2. Положить снимки в исходную папку:
   - `Photos/micro/<название>.HEIC` — снимок с микроскопа
   - `Photos/big/<название>.HEIC` — обычное фото
   Имена файлов внутри `micro` и `big` должны совпадать.
3. Прогнать конвертер (он сожмёт фото и обрежет чёрные поля вокруг круга):

   ```bash
   pip install pillow pillow-heif numpy
   python3 tools/convert.py "путь/к/Photos"
   ```

4. Скрипт напечатает готовый список — скопировать его в `data.js`.
5. В `sw.js` поднять номер версии (`migue-v1` → `migue-v2`),
   чтобы телефоны подхватили обновление.
6. Закоммитить и запушить:

   ```bash
   git add -A && git commit -m "новые предметы" && git push
   ```

Через минуту-две обновление появится по адресу сайта.

## Структура

```
index.html            вся игра: разметка, стили, логика
data.js               список предметов  ← правится чаще всего
photos/micro/*.jpg    снимки с микроскопа (1200×1200)
photos/big/*.jpg      обычные фото (800×800)
icons/                иконка для домашнего экрана
manifest.webmanifest  описание приложения для телефона
sw.js                 офлайн-режим
tools/convert.py      подготовка фотографий
```

## Как сохранить на домашний экран

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран «Домой»».
- **Android:** открыть в Chrome → меню (⋮) → «Установить приложение».

После этого игра запускается как обычное приложение и работает без интернета.
